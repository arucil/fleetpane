# Behavior status

Updated 2026-10-22. This is an initial foundation, not a replacement release.

The user-confirmed target is donut-paseo's useful workflow completeness, with
selective adoption rather than an identical port. OpenCodex and DeepSeek Harness
are the current provider scope; Kimi/GLM are excluded and other providers are
considered only when needed. The
[parity inventory](parity.md) records reference workflows and remaining gaps.
The [product requirements](prd.md) define scope and acceptance criteria;
they are not evidence that a capability has been implemented. Session Host is
the accepted architecture; first-release platform acceptance and numerical
performance targets remain proposals pending M0 validation.
