## Later fixes, removals and non-adoption decisions

- **Speech configuration is not stable across the early implementations.** 1010 removes unshipped aliases; 1026 removes silent local→OpenAI fallback; 1043 disables legacy voice-conversation persistence and 1044 removes the store; 1057/1059 move to voice-agent/audio-only flow. 1167–1170 introduce background readiness/missing-model reasons. These are successive states, not a combined finished design.
- **Control resets need current client identity.** [1006](receipts/1006/selected.patch) schedules control nudges when server-data socket fails to appear. [1163 L96–143](receipts/1163/source-01.txt) rechecks that the client still exists at both delayed stages, preventing a departed client's timer from resetting the shared control channel.
- **Draft command discovery is not passive metadata.** [1248 L420–468](receipts/1248/source-01.txt) explicitly creates a provider session, lists commands and closes it. 1257 routes slash execution through a separate API, then [1259 L2034–2096](receipts/1259/source-01.txt) removes that API in favor of ordinary run/stream with prompt or typed skill input. Keep explicit execution distinct from advertisement/completion. Historical unsafe casts are not a model to port.
- **Archive is not just a list mutation.** 1252 detaches terminal resources; 1260 checks persisted records before auto-archiving the last agent's worktree; [1319 L1670–1723](receipts/1319/source-01.txt) awaits interrupt, persists archive, emits response, then attempts worktree archive. This does not prove full provider/child-process settlement. Preserve existing read-only archived-history browse; 1307's forced redirect is not a useful replacement.
- **Attention and permission state become independent.** [1361](receipts/1361/source-01.txt) gives pending permissions priority even after attention changes. This supports current pending-request behavior rather than requiring a second permission queue.
- **History fixes are invariants to compare, not whole new renderers.** 1017 preserves more rollout fields; 1021 ties initialization completion to snapshot, not RPC ack; 1098 buffers metadata during history sync; 1164 adds cursor paging. [1365 error path](receipts/1365/source-04.txt) preserves old rows on error and [incremental path](receipts/1365/source-03.txt) drops stale/foreign-epoch units and stops at gaps. These readings do not prove the whole synchronization subsystem correct. UI layout/scroll churn, maps and animation changes are not measured speedups.
- **Local repository identity matters.** [1245 L642–702](receipts/1245/source-01.txt) hashes normalized common-directory/root rather than remote URL, so separate clones of one remote need not collide while linked checkouts remain associated. Fleetpane already has Host/project identities; verify actual collision behavior before modifying it. Avoid marker-based `.paseo/worktrees` path guesses at 1289.
- **Packaging repairs are not workflows.** 1238 adds node-pty execute-bit repair, followed by exact dependency pin at 1241; 1211 derives Mac download link from version instead of manual reminders; 1355 rotates updater key after 1347 setup. Dependencies, release links, CI YAML and changelog prose are not installation/runtime proof.
- **Logging changes need separate privacy/retention review.** 1192 removes terminal debugging, 1199 reintroduces it and 1202 removes temporary per-key instrumentation again. [1381](receipts/1381/selected.patch) logs raw provider messages at info. [1395 defaults](receipts/1395/source-03.txt) set console info, file trace, 10m rotation size and two files; [resolver](receipts/1395/source-01.txt) makes levels independent. Do not describe file tracing as opt-in, or assume rotation alone limits all sensitive retention.

Source deduction, not reproduced incident: with a fresh web client `appVisible=true`, `focusedAgentId=null`, and a stale mobile client, [1183 policy](receipts/1183/source-01.txt) can suppress all delivery. No client is actively focused on the target; the fresh web client fails the focused-agent condition then returns false, the stale mobile is suppressed by `hasActiveWebClient`, and push is suppressed by that same web client. Error push is additionally excluded. This is why durable discoverable attention must be independent of delivery. No current Fleetpane defect is inferred from it.
