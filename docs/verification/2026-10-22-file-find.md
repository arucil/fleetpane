# Read-only source Find

Linux X11, 2026-10-22, hidden `fp-model-search` desktop and synthetic files.
Kit's default editor already supported Ctrl+F; this change exposes a Find button
and routes Markdown Preview to its retained Source.
[ADR](../adr/0105-read-only-file-find.md), [receipt](assets/file-find/receipt.json).

- [Three case-insensitive matches](assets/file-find/button-search.png);
  [case-sensitive next occurrence, 2/2](assets/file-find/case-next.png).
- [Chinese matches, 1/2](assets/file-find/chinese-correct.png) and
  [no match, 0/0](assets/file-find/no-match.png). An earlier probe appended to
  the old query; it was repeated with explicit selection.
- [Preview Find switches to Source, 900×560](assets/file-find/small-preview-find.png).
  Source/Preview retain the query; [Reload clears it](assets/file-find/reload-cleared.png).
- Enter [reveals line 7003](assets/file-find/large-tail-next.png) in the complete
  94,530-byte source. Full large-file clipboard Copy remains unverified.
- Native paste into selected source is refused; Ctrl+H exposes no Replace
  controls. [Original full Copy](assets/file-find/clipboard.json) is exactly 67
  bytes, including CRLF and trailing spaces; it matches the captured base64 file.
- Complete Codex and ACP Host snapshots before/after these file actions are
  identical, including the independent pending permission. No provider command
  or model request was needed.

Desktop format, 39 tests, strict all-target Clippy and build pass with
`--manifest-path apps/desktop/Cargo.toml --locked -j2` (format uses `--check`).
This does not accept workspace-wide/terminal/rendered-Markdown search, regex,
editing, persisted queries, installed providers, IME or other platforms.
