The new real-process smoke verifies idle metadata without a history item; exact
title/timestamp/vendor data; omitted and null semantics; list consistency; an
unchanged pending permission and turn; archived restart without prompt replay;
and an injected SQLite failure. Failed metadata commit leaves the old row intact,
fences the Host and emits no metadata event; restart reads the last committed
title. Old archive rows, malformed patch atomicity, stale resident list responses,
active text adjacency and shared projection are covered by unit regressions.
Existing ACP lifecycle, archive, stop and chronology process smokes passed again.
The new smoke is included in CI; remote CI was not run.

Linux native acceptance used hidden workspace `fleetpane-acp-info-20261021`,
task-owned Host/provider processes and synthetic data only:

- Loaded an idle session; an out-of-prompt update changed both directory and
  selected title. Clearing the title restored the default display name.
- A Chinese multiline draft remained exact through updates, verified by native
  clipboard readback. The directory displayed its existing refresh notice.
- Sent one `[permission]` prompt via the UI. While its exact tool request remained
  pending, another title update kept the Host identity, controller owner, request
  and unsent Chinese draft unchanged. SQLite readback confirmed that draft at its
  original Host incarnation, with no send attempt.
- Normal titlebar close exited 0. Restarted only the private Host and reopened the
  UI: title, opaque metadata and exact history items survived; the interrupted
  turn was unknown, no request replayed, Resume context remained explicit and
  Send disabled. Reload conversation preserved this state. The old-incarnation
  draft was not silently migrated. The second normal close also exited 0.

Both UI logs contain the hidden X server's Mesa DRI3 acceleration warning, with
no application error. This is software-rendered functional acceptance, not a
latency/performance measurement. All task-owned windows, workspace and Host/provider
processes were stopped. No shared user provider or desktop was restarted.
