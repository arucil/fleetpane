# Search provider-supplied choices in native conversations

Use GPUI Kit Command for Codex next-message models and ACP select configuration
options. Search display name, stable ID and supplied description; show the ID
separately so duplicate labels remain distinguishable. Never invent catalog
entries, reasoning options or provider capabilities.

An open palette retains its exact session and control lease. Confirmation
rechecks identity, control, pending action, drain and provider type. Codex uses
validated TurnOptions and the supplied default effort; ACP additionally checks
that the option/value still belongs to the selected live session and dispatches
the existing Config command. Selecting a model never sends the message draft.

Catalogs are captured on open. Closing returns previous focus; Escape first
clears a query. Draft entities remain unchanged. Favorites, creation defaults,
opening-time refresh, persistent Codex overrides and other platforms are separate.
